# NYSC_Airplane – 타겟 점수 게임

타겟의 구역을 눌러 8개 팀 점수를 올리는 웹 페이지입니다. (PC 1920x1080 전체화면 기준)

## 진행 방식 (첫 화면에서 선택)
- **PC 단독** : PC 브라우저에만 저장됩니다. 인터넷 연결이 필요 없습니다.
- **모바일 연동** : 휴대폰에서 눌러도 PC 화면에 점수가 바로 반영됩니다.
  1. PC에서 `모바일 연동`을 누르면 방 코드(6자리)와 QR이 나타납니다.
  2. 휴대폰으로 QR을 찍거나, 휴대폰 첫 화면에서 방 코드를 입력합니다.
  3. 휴대폰은 **가로 화면 + 왼쪽 점수판** 배치로 표시됩니다. (PC 화면은 기존 그대로)
  4. 화면 왼쪽 아래의 `방 코드 · 연결 상태` 표시를 누르면 QR 안내창이 다시 열립니다.
- 연동 모드는 점수가 바뀔 때만 작은 메시지 1건을 보냅니다. (주기적 조회 없음, 페이지 파일은 Vercel에서 한 번만 내려받음)

## 파일
- `index.html` : 진행 방식 선택 / `select.html` : 타겟 선택
- `target1.html` ~ `target3.html` : 타겟 페이지 (사각 과녁 / 타원 과녁 / 사각 타일)
- `targets.js` : 타겟 모양과 구역별 점수 (점수를 바꾸려면 이 파일의 숫자를 수정)
- `shared.js` : 점수판(8팀, 되돌리기, 초기화) 및 게임 로직
- `sync.js` : 모드/방/실시간 연결 (Supabase Realtime Broadcast), `config.js` : 연결 설정
- `vendor/` : 실시간 라이브러리(@supabase/realtime-js), QR 생성(qrcode-generator) — 빌드 없이 그대로 사용
- `style.css` : 공통 스타일

빌드 과정이 없는 정적 사이트입니다. Supabase는 테이블 없이 Realtime Broadcast만 사용합니다.
