# NYSC_Airplane – 타겟 점수 게임

타겟의 구역을 눌러 팀 점수를 올리는 웹 페이지입니다. (1920x1080 모니터 / 크롬 기준 최적화)

- `index.html` : 타겟 선택 페이지
- `target1.html` ~ `target3.html` : 타겟 페이지 (사각 과녁 / 타원 과녁 / 사각 타일)
- `targets.js` : 타겟 모양과 구역별 점수 (점수를 바꾸려면 이 파일의 숫자를 수정)
- `shared.js` : 왼쪽 점수판 (7팀, 되돌리기, 초기화) 및 게임 로직
- `style.css` : 공통 스타일

빌드 과정이 없는 정적 사이트입니다.
